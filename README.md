# 50 AI Marios (GBA-style prototype)

This project is a browser-based prototype inspired by GBA-era platformers. It is **not** a ROM, emulator core, or reverse-engineered Nintendo code. Instead, it demonstrates the requested concept: 50 AI-controlled Mario-like runners on a single screen in a simultaneous race.

## Run

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Controls

- `R`: reset all 50 agents with new AI personality values.
