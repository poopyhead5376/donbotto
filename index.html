Donbotto

Automate desktop tasks with free/open LLMs.

Mode: Real-time desktop control (no JSON action schema)

Donbotto streams direct low-level actions through xdotool on Linux to move mouse, type, click, switch windows, and execute workflows live.

Core flow

  1. User gives goal in plain language.
  2. Local/free LLM plans next immediate UI action.
  3. Donbotto executes action instantly with xdotool.
  4. Vision/state check, then continue until done.
