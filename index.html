donbotto

A totally free Linux desktop automation app powered by open-source LLMs. Instead of JSON action plans, Donbotto executes live computer control with xdotool in real time.

Session Preview

$ donbotto run "download the sales csv and email finance"
> launching model: llama3.1-local
> xdotool search --name "Firefox" windowactivate
> xdotool type "https://portal.example.com"
> xdotool key Return
> ... live control running ...
